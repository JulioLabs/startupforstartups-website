# StartupForStartups.com Marketing Website

The official marketing website for StartupForStartups.com - The complete operating system for startups.

## 🚀 Live Website

Visit: [startupforstartups.com](https://startupforstartups.com)

## 📋 Overview

This repository contains the static marketing website for StartupForStartups.com, a platform that helps startups go from zero to one by providing all essential tools in one unified platform.

### Features Showcased
- Job Boards & ATS
- Launch Pages
- Blog & Content Management
- Embeddable Widgets
- Analytics & Tracking
- Custom Domains

## 🛠️ Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid and Flexbox
- **JavaScript (ES6+)** - Interactive functionality
- **Font Awesome** - Icons
- **Google Fonts** - Typography (Outfit font family)

## 🎨 Design System

The website follows the **Future Forward** design system used throughout the StartupForStartups platform:

- **Colors**: Professional green gradients (#059669, #4e9a69)
- **Typography**: Outfit font family for modern, clean appearance
- **Layout**: Responsive grid system with mobile-first approach
- **Components**: Consistent button styles, cards, and interactive elements

## 📱 Responsive Design

The website is fully responsive and optimized for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

## 🚀 Deployment

This website is automatically deployed using GitHub Pages with GitHub Actions:

- **Source**: Main branch
- **Domain**: startupforstartups.com
- **HTTPS**: Enabled
- **Auto-deploy**: On every push to main branch
