<h2 class="section-title">Survey Builder FAQ</h2>
<p class="section-description">
Common questions about building and managing online surveys and questionnaires
</p>
</div>
<div class="faq-grid">
<div class="faq-item">
<h3>How do I create an online survey?</h3>
<p>Creating a survey takes just minutes. Sign in, click "New Questionnaire", add your pages and questions, choose a theme, and publish. Your survey will be live on a branded subdomain and ready to share immediately — no coding or technical setup required.</p>
</div>
<div class="faq-item">
<h3>Can I create multi-page surveys?</h3>
<p>Yes. Our survey builder fully supports multi-page questionnaires. You can add as many pages as needed, reorder them, and control the question flow. This keeps surveys manageable and increases completion rates compared to single long-scrolling forms.</p>
</div>
<div class="faq-item">
<h3>How do I view and export survey responses?</h3>
<p>All responses appear in your real-time response dashboard as they come in. You can export the full dataset as a CSV file in wide format — one row per respondent with each question as its own column — making it easy to analyse in Excel or any spreadsheet tool.</p>
</div>
<div class="faq-item">
<h3>Can I brand my survey with my own colors and fonts?</h3>
<p>Absolutely. With 55+ styling options, you can customize every visual aspect of your survey — background colors, button styles, font families via Google Fonts, text sizes, and more. The live preview lets you see changes instantly before publishing.</p>
</div>
<div class="faq-item">
<h3>Are surveys mobile friendly?</h3>
<p>Yes, all surveys are fully mobile responsive. Whether your respondents open them on a phone, tablet, or desktop, the experience adapts automatically to look great and be easy to complete on any screen size.</p>
</div>
<div class="faq-item">
<h3>Can I get notified when someone completes my survey?</h3>
<p>Yes. You can enable email notifications so you receive an alert each time a respondent completes your survey. You can also connect your survey to external tools via webhooks to push responses directly into your CRM or other systems.</p>
</div>
<div class="faq-item">
<h3>What is a questionnaire subdomain?</h3>
<p>Each survey is hosted on its own subdomain — for example, feedback.yourdomain.com. This gives your survey a clean, branded URL that builds respondent trust. Subdomains are set up automatically when you create a survey.</p>
</div>
<div class="faq-item">
<h3>How many surveys can I create?</h3>
<p>There are no limits on the number of surveys you can create. Build as many questionnaires as you need for customer feedback, product research, onboarding flows, internal team surveys, or any other use case — all included in your plan.</p>
</div>

<script>
let currentSlideIndex = 1;

function changeSlide(direction) {
showSlide(currentSlideIndex += direction);
}

function currentSlide(index) {
showSlide(currentSlideIndex = index);
}

function showSlide(index) {
const slides = document.querySelectorAll('#questionnaireSlider .slide');
const dots = document.querySelectorAll('#questionnaireSlider + .slider-controls .dot');

if (index > slides.length) { currentSlideIndex = 1; }
if (index < 1) { currentSlideIndex = slides.length; }

slides.forEach(slide => slide.classList.remove('active'));
dots.forEach(dot => dot.classList.remove('active'));

if (slides[currentSlideIndex - 1]) {
slides[currentSlideIndex - 1].classList.add('active');
}
if (dots[currentSlideIndex - 1]) {
dots[currentSlideIndex - 1].classList.add('active');
}
}

setInterval(() => {
changeSlide(1);
}, 5000);

document.addEventListener('DOMContentLoaded', function() {
showSlide(currentSlideIndex);
});
</script>
