---
title: "Brand palette"
description: "Set your brand colors and font once per domain, and every new service and widget uses them."
weight: 20
---

A domain's brand palette holds your brand colors and font. New services and widgets on the domain start with them, so you don't have to set them on each one.

## Set the palette

Open the domain's **Settings** from the sidebar and find **Brand Palette**. It has eight values:

| Value | Used for |
|---|---|
| Brand colour | Buttons, links and accents |
| Second brand colour | Special purposes only |
| Main background | The page or widget background |
| Content background | Content areas |
| Borders and subtle backgrounds | Borders and light backgrounds |
| Text | Main text |
| Secondary text | Dates, captions and other details |
| Font | The main font |

Set as many as you like. Leave a value empty to keep each theme's own choice. Your changes save themselves; **Clear palette** removes them all.

## What the palette changes

- **New services and widgets** on the domain start with the palette.
- **Existing services and widgets** don't change on their own. You can:
  - press **Apply to existing components** in the Brand Palette section to update all of them at once, or
  - press **Use domain palette** in one component's [style editor](/docs/styling/themes-and-the-style-editor/).

## Apply to existing components

**Apply to existing components** gives every service and widget on this domain the palette. First a dialog shows how many will change.

- Only the palette colors and font are replaced. Your other style changes stay as they are, and so does the theme.
- Values you left empty in the palette aren't changed.
- Short links have no styles, so they're left out.
- Other domains aren't affected.
- The change shows on your live pages straight away and can't be undone.

The button is disabled until the palette has at least one value.
