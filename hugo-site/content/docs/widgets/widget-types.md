---
title: "Widget types"
description: "What each widget does and where it appears on the page."
weight: 20
---

| Widget | What it does | Where it appears |
|---|---|---|
| [Top banner](/docs/widgets/banners/) | A strip with one or two lines of text and an optional button, for announcements and offers | Across the top of the window; your page moves down to make room |
| [Cookie banner](/docs/widgets/banners/) | Tells visitors your site uses cookies | Across the bottom of the window |
| [Contact form](/docs/widgets/forms/) | Email and message fields, plus an optional name field | Where you paste the code |
| [Form](/docs/widgets/forms/) | A form you build yourself, with your own fields | Where you paste the code |
| [Survey](/docs/widgets/surveys-and-feedback/) | One question, answered with a thumbs up or down, or a 1–5 rating | Bottom-right corner |
| [Feedback](/docs/widgets/surveys-and-feedback/) | A **Feedback** button that opens a 1–5 rating and a comments box | Bottom-right corner |
| [Blog widget](/docs/widgets/blog-links-and-questionnaire-widgets/) | Your latest blog posts as cards | Where you paste the code |
| [Links widget](/docs/widgets/blog-links-and-questionnaire-widgets/) | One of your links pages, inside your site | Where you paste the code |
| [Questionnaire](/docs/widgets/blog-links-and-questionnaire-widgets/) | One of your questionnaires, inside your site | Where you paste the code |

Every widget is added to your site the same way. See [Add a widget to your website](/docs/widgets/embed-a-widget/).

Answers sent through the contact form, form, survey and feedback widgets are listed under [Submissions](/docs/widgets/submissions/).
