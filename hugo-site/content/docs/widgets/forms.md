Both form widgets appear where you paste the widget code. What visitors send is saved under [Submissions](/docs/widgets/submissions/).

## Contact form

A ready-made form with **Email** and **Message** fields, both required. You can change:

| Setting | What it does |
|---|---|
| **Heading** | The title above the form |
| **Include Name Field** | Adds an optional name field |
| **Show Field Labels** | Shows labels (Name, Email, Message) above the fields |
| **Submit Button Text** | The button label |
| **Success Message** | What visitors see after sending |

## Form

Build your own form when you need different fields. Click **Add Field** for each one and choose its type:

- Text Field
- Email
- Textarea
- Select Dropdown
- Radio Group
- Checkbox
- Checkbox Group

For each field you set a **Field Label**, optional **Placeholder Text**, whether it's **Required**, and for text fields a **Maximum Length**. Dropdowns, radio groups and checkbox groups also need their **Options**. Use the arrows to change the order of the fields.

You also set the form's **Form Heading**, **Submit Button Text** and **Success Message**.

## On a links page

Both form widgets can also go on a [links page](/docs/services/links-page/): click **Add Widget** on the page and pick the form. Only forms on the same domain as the links page are offered.
